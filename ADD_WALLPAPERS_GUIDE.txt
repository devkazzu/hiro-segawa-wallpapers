HIRO SEGAWA — ADD WALLPAPERS

1. Open your live website and tap Admin in the navigation.
2. Choose images from your phone.
3. Add a title, category and optional tags.
4. Tap Save wallpaper to drafts.
5. Tap Export for GitHub.
6. Extract the downloaded ZIP.
7. Upload the contents of its wallpapers folder into the wallpapers folder in your GitHub repository.
8. Commit changes. The public gallery will update after GitHub Pages redeploys.

Note: drafts stay in this browser. Export + GitHub commit publishes them to everyone. This static admin page has no secure login.
